Frequently asked questions

Is this color picker free?

Yes, completely free. No signup, no limits, no charges.

What is a HEX code?

A HEX code is a 6-character number for a color, like #6C4DFF. It is used to specify colors in web design and graphics.

Will I get the color name too?

The tool gives HEX and RGB codes. You can also use the ready-made popular color swatches below.

Does my chosen color go anywhere?

No. Everything happens in your browser — no data is sent to any server.

Does it work on phones?

Yes, it works fully on both mobile and desktop.
