Password Generator

Create strong random passwords — made in your browser, never stored anywhere.

How to use

  1. Pick the password length with the slider (6–40 characters).
  2. Tick or untick uppercase, numbers and symbols (@#$).
  3. Press Generate and copy the password with Copy.

Features

  • Length slider from 6 to 40 characters
  • Toggle uppercase, numbers and symbols
  • New password and one-click copy
  • Passwords are never saved or sent anywhere — fully private

Frequently asked questions

How long should my password be?

At least 12, ideally 16 or more characters. Long passwords are extremely hard to crack — pick 16+ with the slider.

Is the generated password stored anywhere?

No. The password is created and shown only in your browser — it never goes to any server or storage.

Do I need a different password for every account?

Yes, very important. If one password leaks, your other accounts stay safe when each has its own password.

Can I trust these passwords?

A long password made of random characters is practically impossible to guess. Still, turn on two-factor authentication wherever available.

Is it free?

Yes, completely free — no sign-up or limits.
