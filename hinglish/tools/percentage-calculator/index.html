Kaise istemal karen

  1. Teeno me se apna hisaab chuno: X ka Y%, X-Y ka pratishat, ya Badlaav %.
  2. Dono box me number daalo aur = dabao.
  3. Nateeja turant neeche dikhega.

Features

  • Teen mode: Y% of X, pratishat hissa, aur badlaav %
  • Chhoot, number aur badhat-ghatat ke rozmarra hisaab
  • Dashamlav (decimal) number bhi supported
  • Button dabaate hi turant nateeja

Aksar puche jaane wale sawal

Chhoot wali keemat kaise nikaaloon?

X ka Y% mode me asli keemat aur chhoot % daalo — chhoot ki rakam mil jaayegi. Use asli keemat se ghataakar final daam pao.

Numberon ka pratishat kaise nikaalein?

X, Y ka kitna % mode chuno — jaise 450 me se 360 number = 80%. Pariksha ke result ke liye sabse kaam ka.

Badhat ya ghatat % kaise niklegi?

Badlaav % mode me puraana aur naya number daalo — jaise daam ₹500 se ₹650 hua to +30% dikhega.

Kya dashamlav number chalenge?

Haan, 12.5% jaise dashamlav maan poori tarah supported hain.

Kya ye free hai?

Haan, poori tarah free — koi sign-up ya limit nahi.
